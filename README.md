# LyricTube GitHub v34.1

YouTube動画と歌詞を同じ画面で管理・再生する、個人利用向けの静的Webアプリです。

## 目的

GitHub PagesでURLを開くだけで使える構成です。Node.jsやローカルサーバーは不要です。
PCだけでなく、v31からスマホでも操作しやすい画面構成に対応しています。

## 崩してはいけない仕様

- YouTube IFrame Playerによる再生
- 曲 / 動画バージョン / Cover / Live管理
- プレイリスト、お気に入り、最近聴いた曲
- 曲開始 / 終了、途中スキップ
- 歌詞表示と自動スクロール
- LRC時間同期
- `♪ 間奏を追加`
- 各歌詞行だけ `-0.5 / -0.1 / +0.1 / +0.5秒`
- JSON書き出し / 読み込み
- `lyrictube.library.v3` 互換
- 同じYouTube動画IDの重複登録防止

## 自動歌詞検索

LRCLIBへブラウザから直接アクセスします。

曲名＋原曲アーティスト、曲名のみ、自由検索、表記ゆれ候補、取得済みYouTubeタイトルを順番に試します。
LRCLIBの仕様に従って `Lrclib-Client` ヘッダーを使用し、検索間隔も空けています。

### Win + Shift + T と歌詞OCR

WindowsでPowerToys Text Extractorを使っている場合、通常は `Win + Shift + T` で画面上の歌詞を範囲選択して文字化し、LyricTubeの歌詞欄へ `Ctrl + V` で貼り付けできます。

これはWindows側のショートカットなので、GitHub PagesのWebサイト自体がグローバルに取得するものではありません。同期画面では別途 `Shift + T` を使うと、選択中の歌詞行へ現在時間を打刻できます。

## データ保存

通常の編集内容はブラウザ `localStorage` の `lyrictube.library.v3` に保存します。

v31では、初めて開いた端末にlocalStorageの曲データがまだ無い場合、`data/library.json` を共通ライブラリとして読み込みます。設定画面の「共有JSONを再読み込み」から、あとで明示的に読み直すこともできます。

GitHub Pagesは静的サイトなので、サイト上で曲を追加・編集しても `data/library.json` 自体へ自動書き込みはされません。各端末で行った変更は、その端末のlocalStorageへ保存されます。

### 友達へ同じ曲データを配る方法

1. 自分のLyricTubeで `書き出し` を押す
2. 出力されたJSONの内容をリポジトリの `data/library.json` に置く
3. 友達が初めてサイトを開くと、そのJSONが初期ライブラリとして読み込まれる
4. すでに使ったことがある端末では、設定の `共有JSONを再読み込み` を押す

`共有JSONを再読み込み` は、その端末の現在の曲・プレイリストを共有JSONで置き換えるため、必要なら先に `書き出し` でバックアップしてください。

## 簡易アクセス

v31.1では、通常モードとゲストモードの2通りで入れます。

- 通常モード: アクセスコード `2526`。全機能を使用可能。
- ゲストモード: パスワード不要。再生、歌詞、お気に入り、プレイリストを利用可能。
- ゲストでは曲追加、曲情報編集、削除、動画バージョン編集、開始/終了/スキップ、歌詞同期編集を非表示にします。
- お気に入りとプレイリストはゲスト端末のlocalStorageへ保存されます。

これは本格的な認証ではなく、GitHub Pages上のファイルを見ればコードや共有JSONを確認できる簡易方式です。私的利用・友達間利用を前提としています。

### ゲストモード

最初の画面で `ゲストで入る` を押すだけで利用できます。ゲスト中は画面上部に `GUEST` バッジを表示します。

通常モードへ切り替えたい場合は、新しいタブで開くか、そのタブのsessionStorageを消してからアクセスコード `2526` を入力してください。

## 注意点

- ブラウザのサイトデータ削除でlocalStorageも消えるのでJSONバックアップ推奨。
- v34の端末音源はIndexedDBに保存するため、サイトデータ削除やOS/ブラウザによるストレージ整理で音源本体が消える場合があります。
- 埋め込み禁止のYouTube動画は再生できません。
- LRCLIBやYouTube側の障害時は外部機能のみ一時的に使えない場合があります。
- v31.1のアクセスコードは公開リポジトリ上で確認できる簡易方式であり、秘密情報を守る用途には使わないでください。
- APIキーなど、本当に秘密にする必要がある情報はリポジトリへ追加しないでください。

## v31.2 かいと用ライブラリ分離

- `2526` で入る通常モードを「かいと」用として扱います。
- かいと用の初期/再読み込み元は `data/library-kaito.json`。
- ゲスト用の初期/再読み込み元は従来どおり `data/library.json`。
- 通常モードとゲストモードのlocalStorageを別キーへ分離し、同じ端末で使っても曲データが混ざりにくい構成に変更。
- v31.2以前の `lyrictube.library.v3` が残っている場合は、初回のみかいと側へ移行します。
- GitHub Pagesは静的サイトのため、サイト内編集が `data/library-kaito.json` へ自動反映されるわけではありません。各端末の編集はその端末へ保存されます。

### かいと用JSONの更新

LyricTubeの書き出しJSONを `data/library-kaito.json` として置き換えると、新しい端末で `2526` ログインした人が同じ初期ライブラリを利用できます。既に利用済みの端末では設定の「共有JSONを再読み込み」を使用します。
ゲスト側のライブラリを更新したい場合だけ `data/library.json` を変更します。

## v32 Supabaseクラウドアカウント

- Supabaseの `LyricTube` プロジェクトへアカウント・ライブラリ・セッションを保存します。
- `kaito` は管理者アカウントで、パスワード `2526`。ログイン画面でアカウント名を空欄にした場合も `kaito` として扱います。
- 管理者は設定の「アカウント管理」から友達用アカウントを追加・削除・パスワード変更できます。
- 新規アカウントは空のライブラリ、または現在のライブラリを複製して作成できます。
- 各アカウントの曲・プレイリスト・設定はSupabaseへ自動保存され、別PC/スマホでも同じアカウントで利用できます。
- ブラウザからDBテーブルを直接操作せず、`lyrictube-api` Edge Functionを経由します。
- パスワードはPostgreSQL `pgcrypto` のbcrypt形式でハッシュ保存します。
- ゲストは引き続き端末内だけの別データです。
- `lyrictube.library.v3` のライブラリJSON構造は維持します。
- かいとのクラウドライブラリが空の場合、既存PCのかいと用localStorageまたは `data/library-kaito.json` から初回移行を試みます。

## v33 差分クラウド同期

- ブラウザ内では従来どおり `lyrictube.library.v3` を使用します。
- Supabaseでは曲・プレイリスト・設定を分割して保存します。
- 通常の編集では、変更された曲・プレイリスト・設定だけを約900msまとめて同期します。
- ログイン時は分割データをv3ライブラリJSONへ再構成して読み込みます。
- JSON全読み込みや全リセットなど、全置換が必要な操作だけライブラリ全体を置き換えます。
- 曲とプレイリストの並び順は `sort_order` で維持します。
- 旧 `lyrictube_libraries` の全JSONは移行バックアップとして当面残します。
- 同じ項目を複数端末から同時編集した場合は、最後に同期された内容が優先されます。

## v34 端末音源・バックグラウンド再生強化

- 選択中の曲 / 動画バージョンへMP3・M4A等の端末音源を割り当てられます。
- YouTube登録済みの曲へ端末音源を割り当てた場合、その端末では端末音源を優先し、解除するとYouTubeへ戻ります。
- YouTube URLなしの「端末音源だけの曲」も新規作成できます。
- 音源ファイル本体はSupabaseへアップロードせず、端末ブラウザのIndexedDBへ保存します。
- クラウドへ同期する `lyrictube.library.v3` の曲・歌詞・プレイリスト形式は変更しません。
- 同じクラウドアカウントを別端末で開いても音源ファイル自体は共有されません。端末音源だけの曲では、その端末でファイルを再登録します。
- HTMLAudioElement + Media Session APIを使用し、対応スマホではバックグラウンド再生、ロック画面/通知領域の再生・停止、前/次、シーク、曲情報表示を利用できます。
- 既存の歌詞同期、開始/終了範囲、スキップ、ボトムプレイヤー、音量、前/次曲操作を端末音源でも利用できるようにします。
- ゲストは既存曲へ端末音源を割り当て可能ですが、新しいクラウド曲の作成は表示しません。

### 制限

- iPhone / Androidのバックグラウンド継続可否はOS・ブラウザの省電力制御にも依存するため、すべての端末で画面OFF再生を保証するものではありません。
- IndexedDBの音源はその端末だけのデータです。JSON書き出しには音源ファイル本体を含めません。
- 1ファイルの登録上限は250MBです。

## v34.1 端末音源操作の補強

- 端末音源再生中のボトムプレイヤー「再生 / 一時停止」をローカル音源へ確実に接続。
- 同期エディタの「再生 / 一時停止」をローカル音源へ確実に接続。
- YouTube URLが無い端末音源専用曲でもボトムシークを有効化。
- 端末音源専用曲でも現在位置から曲開始 / 曲終了を設定可能。
