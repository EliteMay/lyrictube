# LyricTube v0.9.0 バージョン表記整理

日付: 2026-08-29

## 目的

旧 `v31 / v35 / v36` のような「作業回数に近い番号」を、そのまま製品UIへ見せないようにする。

VReviewの `v0.4.3` 表記を参考に、LyricTubeもユーザー向けバージョンと技術的なビルド番号を分離する。

## 変更内容

- ユーザー向けバージョンを `v0.9.0` に変更
- ブラウザタブは `LyricTube` のみ表示
- サイドバーのバージョンバッジは `v0.9.0` 表示
- 設定画面も `v0.9.0` 表示
- `GH v31 / GH v35` のようなGitHub世代番号を通常UIから隠す
- 内部ビルド番号を `20260829-8` に分離
- `version-meta.js` を新設
- `profile-data.js` の追加機能スクリプトのキャッシュキーを日付revision方式へ変更
- READMEを現在仕様中心に整理し直した

## バージョンルール

### 公開バージョン

Semantic Versioning形式。

- MAJOR: 大きな仕様段階
- MINOR: 新機能 / まとまった改善
- PATCH: 不具合修正 / 小改善

正式安定版までは `v0.x.x` を使用する。

### 内部ビルド

`YYYYMMDD-revision` を使用する。

例: `20260829-8`

通常UIでは目立たせず、キャッシュ更新とデバッグ用に扱う。
