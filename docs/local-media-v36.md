# LyricTube v36 端末ファイル対応

## 目的

YouTube URLだけでなく、手元の音声・動画ファイルをLyricTubeへ直接登録して、歌詞表示・同期・プレイリスト等の既存機能と一緒に利用できるようにします。

## 追加場所

### 新しい曲

`＋ 曲を追加` → `最初の再生ソース` で以下を選択します。

- YouTube
- 端末ファイル（MP3 / MP4）

端末ファイルを選ぶとYouTube URL欄の代わりにファイル選択欄が表示されます。

### 既存曲へ別バージョンを追加

`動画バージョンを追加` でも以下を選択できます。

- YouTube
- 端末ファイル（MP3 / MP4）

Cover / Live / Acousticなどの既存の動画タイプはそのまま利用できます。

## 対応形式

### 音声

- MP3
- M4A
- AAC
- WAV
- OGG / OGA
- OPUS
- FLAC

### 動画

- MP4
- WebM
- M4V

ブラウザが実際にデコードできるコーデックに依存します。MP4はH.264 + AACが最も互換性が高い想定です。

## 保存方法

- 曲名、アーティスト、歌詞、バージョン情報などのライブラリ情報は従来の保存・クラウド同期対象です。
- MP3 / MP4などのファイル本体はSupabaseやGitHubへアップロードしません。
- ファイル本体はブラウザのIndexedDB `lyrictube.localMedia.v1` に保存します。
- 別端末では同じ曲情報が存在しても、ファイル本体を再登録する必要があります。
- ブラウザのサイトデータ削除やストレージ整理でファイル本体が消える場合があります。

## サイズ

1ファイル最大1GBとして受け付けますが、実際に保存できる容量はブラウザ・OS・端末の空き容量に依存します。

## 既存仕様との互換性

- `lyrictube.library.v3` を維持します。
- 既存のYouTube再生を維持します。
- v34の端末音源データは削除・自動移行しません。
- 新しい端末ファイルはバージョンの `source: "localmedia"` で識別します。
- `type` は従来どおり `original / cover / live / acoustic` 等の意味に使い、保存元の種類とは分離します。
- 開始 / 終了位置、スキップ区間、歌詞オフセット、同期エディタは端末メディアでも利用できるよう再生時間APIを共通化します。

## 未確認

- iOS Safariにおける長時間動画・大容量IndexedDBの安定性。
