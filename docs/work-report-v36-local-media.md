# 作業報告 v36 - 端末MP3 / MP4対応

日付: 2026-08-29

## 今回変更した内容

- 曲追加ダイアログへ `YouTube / 端末ファイル（MP3 / MP4）` の再生ソース切替を追加。
- 端末ファイルから新しい曲を直接作成できるようにした。
- 既存曲の別バージョン追加でもYouTubeと端末ファイルを選択可能にした。
- MP3等の音声に加えてMP4 / WebM / M4V動画を直接再生可能にした。
- 端末動画をプレイヤーカード内へ表示。
- 端末ファイルでも開始・終了・自動スキップ・歌詞同期用の現在時間取得を利用できるよう再生処理を接続。
- 別端末でファイルが無い場合に再登録導線を表示。
- 既存のv34端末音源機能と保存DBを分離し、既存データを削除しない構成にした。

## 変更したファイル

- `local-media.js` 追加
- `profile-data.js` 更新
- `docs/local-media-v36.md` 追加
- `docs/work-report-v36-local-media.md` 追加

## 保存仕様

- ライブラリメタデータ: 従来どおり `lyrictube.library.v3`
- 新端末メディア本体: IndexedDB `lyrictube.localMedia.v1`
- GitHub / Supabaseへファイル本体はアップロードしない。
- 端末メディア版のバージョンは `source: "localmedia"` を持つ。

## 維持した仕様

- YouTube IFrame Player再生
- 曲 / 動画バージョン構造
- Cover / Live / Acoustic等の動画タイプ
- 歌詞、LRC、動画別同期
- 開始 / 終了 / スキップ
- プレイリスト / お気に入り
- `lyrictube.library.v3` 互換
- v34端末音源の既存IndexedDBを変更・削除しない

## 修正した不具合 / UI問題

- 従来は端末音源機能が曲作成後のプレイヤー側にあり、`＋ 曲を追加` から端末ファイルを選ぶ入口が分かりにくかった。
- 新規曲追加画面へ明示的なソース選択を追加した。
- MP4再生時に音声用の端末ファイルUIが動画の上へ被らないよう表示処理を分離した。
- 端末ファイル版からYouTube版へ戻した場合に `source: localmedia` が残らないよう後処理を追加した。

## 未確認

- 実ブラウザでの最終クリック操作。
- Windows上でのMP3 / MP4実ファイル保存・再生。
- Android / iPhoneでの大容量ファイル保存。
- MP4の各種コーデック互換性。
- ブラウザごとのIndexedDB実容量上限。

## 完了条件

以下を実機確認できれば今回の機能を完成扱いにできます。

1. `＋ 曲を追加` に `端末ファイル（MP3 / MP4）` が表示される。
2. MP3を選択して曲を保存・再生できる。
3. MP4を選択してプレイヤー内で映像と音声を再生できる。
4. 再読み込み後も同じ端末ではファイルが残る。
5. 端末ファイルで歌詞同期・シーク・開始終了位置が機能する。
6. 既存YouTube曲とv34端末音源が壊れていない。
