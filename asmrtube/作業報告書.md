# ASMRTube 作業報告書

## 今回変更した内容

LyricTubeとは分離したASMR専用Webアプリ `ASMRTube v1` の初期実装を追加しました。

## 変更したファイル

- `asmrtube/index.html`
- `asmrtube/styles.css`
- `asmrtube/app.js`
- `asmrtube/data/tags.json`
- `asmrtube/README.md`
- `asmrtube/作業報告書.md`

## 追加した機能

- YouTube URLからASMR登録
- YouTube動画IDの重複チェック
- 配信者・タグ・評価・睡眠向けフラグ
- お気に入り
- 最近聴いた
- プレイリスト
- 検索 / タグ絞り込み
- YouTube IFrame Player再生
- 作品別音量保存
- 前 / 次の再生
- A-B区間リピート
- スリープタイマー
- YouTubeコメント本文からタイムスタンプ抽出
- `m:ss` / `h:mm:ss` 解析
- タイムスタンプ編集プレビュー
- 耳かき / 梵天 / 囁き / 左右耳などの簡易タグ自動判定
- タイムスタンプから直接シーク
- JSONバックアップ / 復元
- レスポンシブUI

## 修正した不具合

新規プロジェクトのため既存不具合修正はありません。

## 守った仕様

- LyricTubeの `main` ブランチは変更していません。
- `lyrictube.library.v3` は変更・参照していません。
- ASMRTube用に `asmrtube.library.v1` を使用します。
- APIキーや秘密情報は追加していません。
